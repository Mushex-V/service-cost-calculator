# Service Cost Calculator

An interactive service cost calculator for real-time estimation, built for a professional portfolio.

## 🚀 Features
- Dynamic real-time calculation based on selected options.
- Clean, minimalist UI focused on great UX.
- Fully responsive layout for all screen sizes.
- Pure JavaScript logic for handling user input and state.

## 🛠 Tech Stack
- **HTML5** — Semantic markup
- **SCSS (Sass)** — Modular styling (variables, mixins, compiled to CSS)
- **JavaScript (ES6+)** — Interactivity and calculation logic
- **Git & GitHub** — Version control and deployment

## 📁 Project Structure
